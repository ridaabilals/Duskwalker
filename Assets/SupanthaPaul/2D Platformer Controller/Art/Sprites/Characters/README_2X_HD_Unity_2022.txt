DUSKWALKER ORIN - 2X HD ANIMATION PACKAGE
===========================================

Resolution:
- Every animation frame is 272 x 272 pixels.
- Run sheet: 2176 x 272 pixels (8 frames).
- Original frame counts and animation order are preserved.
- The Fall sheet uses upright falling poses, not sitting poses.

Recommended Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Pixels Per Unit: 128
- Filter Mode: Bilinear
- Compression: None
- Max Size: 4096
- Generate Mip Maps: Off
- Mesh Type: Full Rect

The included .meta files already contain 272 x 272 slicing and 128 Pixels Per Unit.
Copy the Player_Reko folder into Assets and keep each PNG beside its .meta file.

Important:
- Keep the Player GameObject Transform scale unchanged.
- Keep the collider on the root Player GameObject.
- Do not resize the collider for individual animation frames.
- If Unity has cached the old texture, right-click the folder and select Reimport.
